Website & CRM Integrations

Connect your organization’s backend without exposing credentials to website visitors.

Keep API keys private. Send integration requests from your server only. Do not embed the organization API key or webhook signature secret in browser JavaScript, HTML, public repositories, or mobile apps. The current browser tracker is for local development only because it uses the organization API key.

1. Create or obtain an organization API key

Use the organization provisioning endpoint in a trusted admin environment. Save the returned key in your server’s secret manager or environment configuration; it is shown only once.

POST /api/organizations
X-LeadPulse-Bootstrap-Key: <bootstrap-secret>
Content-Type: application/json

{"name":"Your Company"}

2. Send events from your backend

When your application receives a signup or form submission, your server can call:

POST /api/integrations/lead-events
X-LeadPulse-Api-Key: <organization-api-key>
X-LeadPulse-Timestamp: <current-unix-time-seconds>
X-LeadPulse-Signature: sha256=<HMAC-SHA256-signature>
X-LeadPulse-Idempotency-Key: <unique-event-id>
Content-Type: application/json

{
  "eventType": "FORM_SUBMITTED",
  "visitorId": "visitor-id-from-consented-tracking",
  "email": "person@example.com",
  "name": "Prospect Name",
  "company": "Example Ltd",
  "pageUrl": "https://company.example/request-demo",
  "consentGiven": true
}

Supported event types: FORM_SUBMITTED, DEMO_REQUESTED, ACCOUNT_CREATED, and PURCHASE_COMPLETED. Each event needs a fresh idempotency key and a timestamp within five minutes of server time.

3. Sign the webhook on your server

Generate the signature using HMAC-SHA256 with your organization API key and this exact newline-separated canonical string:

timestamp
EVENT_TYPE_UPPERCASE
visitorId
email_lowercase
name
phone_or_empty
company_or_empty
pageUrl_or_empty

Send the signature as sha256=<lowercase-hex-digest>. Sign the normalized values shown above. Keep the API key in your server secret store.

4. Read organization tracking analytics

GET /api/analytics/tracking
X-LeadPulse-Api-Key: <organization-api-key>

The response includes event totals, unique visitors, identified visitors, visitor-to-lead conversion, event types, and top pages. Call it from a trusted backend and return only the necessary values to authenticated organization users.

5. Rotate or revoke a key

Rotate a key from a trusted backend using the current key. The replacement is returned once and the old key is invalidated.

POST /api/organizations/api-key/rotate
X-LeadPulse-Api-Key: <current-organization-api-key>

DELETE /api/organizations/api-key
X-LeadPulse-Api-Key: <current-organization-api-key>
